# Innovial Shift visual direction

## Identity

- Keep Innovial’s existing white logotype, deep navy `#0F172A`, and blue `#3B82F6`.
- Carry the existing site’s direct, technical character into a developer product page.
- Keep Geist as the site typeface, as already configured by the project.

## Product expression

- Use an illustrative code diff for the code migration workflow. Label it clearly as an illustration.
- Repeat dependency lines in the repository context graphic to connect the page to codebase structure.
- Keep claims concrete and mark planned capabilities as planned.

## Dials

- ENERGY 2: focused and technical, with the navy hero and blue accent carrying the main emphasis.
- RHYTHM 3: alternate between the split hero, broad product statement, capability panels, workflow row, dark Claude section, and closing contact section.
- MOTION 1: keep the page still, apart from native anchor scrolling. Respect reduced-motion preferences.

## Page decisions

- The deep navy and white surfaces separate decision-making context from detailed reading, while Innovial blue marks dependency paths and primary actions.
- Geist keeps the page readable for long product explanations, with monospace reserved for repository and API labels where code vocabulary benefits from it.
- Sections alternate between editorial explanation, an illustrative migration artifact, and structured records so the page follows the way a migration is discussed.
- Thin dependency lines appear only inside repository diagrams to show impact paths; they are not used as a decorative background.
- The page stays static because the product promise is reviewable reasoning. Movement would distract from the content and declared MOTION 1 direction.
